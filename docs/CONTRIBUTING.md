# Guia de Contribuição

## Git Flow
- Crie uma branch a partir da main: `feat/nome-da-feature`
- Nunca faça push direto na main (convenção do time — repos privados no GitHub Free)
- Abra Pull Request com 2 aprovações obrigatórias (convenção, não regra automática)

## Setup Local
1. `cp .env.example .env` e preencha
2. Configure o ambiente (veja README)
3. Desenvolva e commite seguindo Conventional Commits

## Documentação
- Decisões técnicas → salvar em `/docs/decisoes/`
- Commits seguem Conventional Commits
